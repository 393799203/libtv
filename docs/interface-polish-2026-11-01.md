# 网站界面精修

采用已安装的 Impeccable 4.8.0，执行现有界面的 polish 流程。
保留漫蛙品牌标、暗色主题、青色操作强调及原有作品、项目和创作流程。

本轮落实：

- 导航明确区分作品广场、我的项目、社区，显示当前页面，保留指南和账户操作。
- 删除首页无功能的英文装饰标签，提供可识别的页面标题和区域标题。
- 作品封面与标题、作者分区，手机不再把全部文字压在缩略图上。
- 视频缺失封面和未设置头像使用本地占位，不请求与内容无关的随机图片。
- 项目名称与更新时间在封面下展示，删除与打开是两个独立按钮；
  键盘聚焦时删除操作可见，封面加载失败退回项目首字。
- 按用户反馈进一步压缩卡片：最近项目与我的项目的名称、更新时间同排，
  作品名称、作者与点赞信息同排，底部固定单行；长名称截断，悬停提供完整标题，
  加载占位同步缩短，桌面和手机均不再占两行。
- 作品和项目的首次加载使用结构占位；搜索无结果、加载失败提供对应恢复操作，
  不将网络错误显示为“没有项目”。
- 共享键盘焦点、文字选中、输入光标及减少动态效果；画布工具按钮补充操作名称。
- 个人中心的小屏输入与操作尺寸增大，保持原有两栏/单列结构。

验证：

- 类型检查、生产构建通过。
- Impeccable 对本轮改动的单次检测结果为空。
- 320/390/768/1440px 浏览器回归覆盖导航可访问、无横向溢出、
  作品标题布局、封面缺失、搜索与错误恢复、键盘删除确认、空项目创建。
- 原有助手完整流程和个人中心/推荐注册回归通过。
- 16 个助手逻辑测试及推荐链接测试通过。

截图与浏览器布局数据由本地隔离测试产生，测试拦截全部业务接口，
不创建真实项目、充值或生成任务。部署仅替换前端，保留上一版镜像和静态文件备份。
